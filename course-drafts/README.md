# 待核验课程工作区

这里先把私人资料中的**主题线索**转成原创课程草稿，以便前端和 Java 两条路线并行扩展。`course-drafts/` 不在 `build_public.py` 的发布白名单中；草稿也不进入 `window.LESSONS`、知识点统计或在线搜索。

每篇草稿都标明 `待核验`，写出学习目标、暂定解释、可操作实验和必须查证的问题。暂定解释不是正确答案。编辑时先确认资料页码，再依据官方文档、规范、固定版本源码或可复现实验核对；发现错误就修正；完成后才转入公开课程文件，并在审查记录里留下版本和依据。一次可批量起草多个主题，再按风险优先级集中核验。

私人 PDF、图片、提取全文和密码只留在 `private-data/` 或用户原目录；本工作区只保存独立编写的课程文字及必要的来源定位。

状态流转：`待核验草稿` → `核验中` → `已核验并发布`。若查不到可靠依据，保持草稿状态；不以“已经写完”代替“已经核对”。
