# 课程「例子」里的代码块约定

学习页用 `RichBlocks` 渲染 `lesson.example`（参考答案同样支持）。正文里可用 Markdown 围栏：

````markdown
先说明要观察什么。

```js
const a = { id: 1 }
```

再写观察到的结果（中文）。
````

## 写法

1. **有可运行的最小片段就写进围栏**；纯场景叙述可以没有代码。
2. 片段宜短（大约 ≤20 行），服务本课一个结论，不要贴整文件。
3. 围栏语言标签用常见缩写：`js` / `ts` / `tsx` / `css` / `java` / `sql` / `bash`。
4. 围栏**外**仍可写课 id 反引号（会链到那一课）；围栏**内**不要依赖自动改写。
5. 源文改 `curriculum/*.js` 后执行 `cd web && npm run export:curriculum`。

## 批量补代码

试点集中在 `curriculum/example-code-blocks.js`（导出时最后覆盖 `example`）。扩课时往该表追加 id，或把围栏直接写进对应 coverage 的 `example` 字段。

## 相关实现

- 拆分：`web/src/data/reading.ts` → `splitFencedBlocks`
- 渲染：`web/src/components/RichBlocks.tsx`
- 样式：`web/src/styles/_reading.scss` → `.lesson-code`
