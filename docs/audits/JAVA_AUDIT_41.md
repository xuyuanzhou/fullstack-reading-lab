# 资料核验记录（批次 41）

线程讲义把“进一个 synchronized 方法”说成锁死该对象全部方法，并把线程状态缩成四态。效率文宣称 final 类快 50%，面试题把 `2<<3` 当正经乘法。EJB/Struts/JDO 标不适用。

| 原件 | 说法 | 课程 |
| --- | --- | --- |
| 线程编程方面（三份） | 进一个同步方法就不能进其它方法；只有四态 | `java-sync-not-all-methods`、`java-thread-six-states` |
| java 代码效率优化 | final 类快 50%；方法同步快于代码块 | `java-final-not-fifty-percent` |
| Java 基础面试题集 / 32 问 | 2<<3 当 2×8；同步锁死对象 | `java-shift-not-times-eight`、`java-sync-not-all-methods` |
| EJB、Struts、JDO、搜狗实践随笔 | 过时容器 / 非说法 | 不适用 / 题干 |
