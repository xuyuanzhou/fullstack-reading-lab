# 关卡跳转时长

日期：2026-10-13。标准：从离开上一页到下一页可以阅读，**不超过 2 秒**。转场遮罩和课文下载并行，取较慢的一边，不把两段时间相加。

## 场景

没有「过关后自动跳走」。读完要点下一节，是读者自己点「记为已读，下一节」。点下去先把已读写进内存，路由一变就把学习记录落盘。失败后再试不整页刷新。

| 场景 | 怎么走 | 遮罩 | 这次量到的可阅读时间 |
| --- | --- | --- | --- |
| 同一轨里换一节（含记为已读后的下一节） | 课文地址不变层 | 无 | 4ms（正文已预取） |
| 首页或关卡地图进一节 | 拼接 | 1000ms | 1000ms，正文就绪 3–6ms |
| 首页进关卡地图 | 淡入淡出 | 1500ms | 1500ms。雾面慢慢盖上再揭开，正文仍在这 1.5 秒里就绪 |
| 从一节或地图返回 | 拉远 | 900ms | 900ms，正文 7–13ms |
| 系统要求减少动态效果 | 不播遮罩 | 0 | 6ms |
| 课文没打开 | 页内「再试一次」 | 不换页 | 只重取这一课的文件 |

弱设备（2 核及以下、内存不超过 2GB、省流量或没有 WebGL）遮罩改为 800ms。4 倍 CPU 节流下，返回首页仍然是 900ms，正文 13ms。390px 宽进一节没有横向溢出，总时长 1000ms。

## 瓶颈

原先一进课文要下载整轨正文。Java 那份约 1.7MB。慢速 3G（约 400kbps、400ms 延迟）下，这一份在 2 秒内下不完，请求被中止。单课文件 `idempotency.json` 是 2367 字节，同样网络下 478ms。

现在运行时只加载这一课，并在空闲时预取首页、关卡地图、课文这三个页面，以及当前关的下一节。点链接、键盘焦点落到链接上时，再预取那一节。学习记录在跳转时立刻落盘，不放到后台请求里。

整轨 JSON 仍留给导出和检索，页面不再引用它。

## 以后怎么守

- 预算写在 `web/src/transition/jumpBudget.ts`：`JUMP_BUDGET_MS` 是 2000，单课文件不超过 `LESSON_BODY_BUDGET_BYTES`（40000 字节）。
- `scripts/jump-budget.test.mjs` 核对每一课都有自己的文件，且和整轨导出一致、不超过字节预算。
- `scripts/page-transition.test.mjs` 核对三种遮罩都在 0.8–1.5 秒，并且不超过 2 秒。
- 浏览器里 `window.__labJumps()` 看最近 20 次。超过 2 秒会在控制台警告，字段是 `readyMs`（正文就绪）和 `overlayMs`（遮罩）。
- 新课要走 `scripts/export-curriculum.mjs`。它会写 `web/src/data/bodies/<track>/<id>.json`。不要在页面里再 `import` 整轨正文。
