## 2026-10-06：Vue Modal、编译标记与 MySQL 预处理、缓冲池、行上限

对照同一份 Vue PDF 第 17–31 页和同一份 MySQL PDF 第 1、4–6 页后发布第 07 批：编程式挂载和 Teleport 不等于完成对话框；补丁标记、静态提升和事件缓存都有编译条件，32 现名 `NEED_HYDRATION`，-1 现名 `CACHED`。`PreparedStatement` 在 Connector/J 默认是客户端预处理。Buffer Pool 默认 128MB，80% 只属于专用机建议；大于 1GiB 时实例数有默认公式。单列 `VARCHAR` 的 latin1 手册例子是 65533，不是再减 1 后除以 3。`SELECT *` 仍可使用过滤索引，`Using index` 才要求覆盖。页码级结论见 [Vue 第 07 批](audits/FRONTEND_AUDIT_07.md) 与 [MySQL 第 07 批](audits/JAVA_AUDIT_07.md)。`read_buffer_size` 仍待核。这仍不是两份 PDF 的全文验收。

## 2026-10-06：MySQL WHERE 与 HAVING

对照同一份 MySQL PDF 第 6 页第 16 题后发布第 08 批：WHERE 不能引用 SELECT 别名和聚集函数；HAVING 筛组，可写聚集与别名，但不是“只能写别名/聚集”。无 GROUP BY 且无聚集时 HAVING 会并进 WHERE；带分组的 HAVING 接近最后执行且手册写明无优化，行级条件应写回 WHERE。页码级结论见 [MySQL 第 08 批](audits/JAVA_AUDIT_08.md)。这仍不是整份 PDF 的全文验收。

## 2026-10-06：Vue 设计目标 / Proxy / 树摇「更快」，以及 MySQL 剩余题

结案《Spring面试题（含答案）.pdf》：作用域菜单含 request/session/application/websocket，勿背 global-session；单例≠线程安全。React 续核：Effect 时序非像素定理；Fiber 非 OS 协程；虚拟 DOM 不保证永远更快；props 不必默认 Effect 同步进 state。见 [JAVA_AUDIT_11](audits/JAVA_AUDIT_11.md)、[FRONTEND_AUDIT_09](audits/FRONTEND_AUDIT_09.md)、[FRONTEND_AUDIT_10](audits/FRONTEND_AUDIT_10.md)。Router 勿背 Switch；「最新」勿停在 16 营销清单。GDSFP 不是拷 props 的默认通道；createClass 已不在核心包；新 Redux 走 Toolkit。见 [FRONTEND_AUDIT_11](audits/FRONTEND_AUDIT_11.md)、[FRONTEND_AUDIT_12](audits/FRONTEND_AUDIT_12.md)。SSR 不是少 HTTP / 一份 HTML 带齐数据；复用状态优先自定义 Hook 而非 HOC 当 mixins 替身。见 [FRONTEND_AUDIT_13](audits/FRONTEND_AUDIT_13.md)。Context 已是 createContext 稳定 API，不是实验功能，也不再靠 getChildContext。见 [FRONTEND_AUDIT_14](audits/FRONTEND_AUDIT_14.md)。《分布式高并发.pdf》主题抽查（CAP、Kafka 顺序、XA、布隆、缓存、限流、一致性哈希）已写入核对队列 D1–D7，仍非逐页验收。另结案三份 3 页题单：Nginx 的 gunzip 不是压到上游、模块可用 load_module；MyBatis 的 RowBounds 默认内存分页；Kafka 存活不再绑 ZooKeeper，acks=all 等的是 ISR。见 [JAVA_AUDIT_12](audits/JAVA_AUDIT_12.md)。另结案 ES 七题与两份 Redis 短 PDF：Lucene 不是 B+ 树对比；Redis 没有现行 VM 换页，STRING 不是 1GB/512KB；淘汰策略不止旧六种 LRU。见 [JAVA_AUDIT_13](audits/JAVA_AUDIT_13.md)。另结案十份 Java 短 PDF：Calendar 不是单例；唯一索引写入常用不上 change buffer；RestController 可替代 JSON 的 Controller；MongoDB 4.0 起有多文档事务；ZK 的 timeliness 不是最终一致性；Boot 内嵌 Tomcat，DevTools 是快速重启；RabbitMQ 队列可限长且没有 inner-msg-id 幂等；Enumeration 并不快一倍。见 [JAVA_AUDIT_14](audits/JAVA_AUDIT_14.md)。另结案阿里专场与 List/HTTP/ActiveMQ 短篇：Executors 工厂常无界；偏向锁非现行默认；SETNX 过期说法过时；main 不是静态块；FutureTask 不再基于 AQS；读写锁不能升级；asList 是固定视图；PATCH 来自 RFC 5789；ActiveMQ prefetch 会钉住消费者。见 [JAVA_AUDIT_15](audits/JAVA_AUDIT_15.md)。另结案 CAS/ABA、Boot 默认 CGLIB、LinkedBlockingQueue 无界、DCL 要 volatile、trim≠strip、缓存三类、503 不是宕机、RocketMQ 不是无限内存队列。见 [JAVA_AUDIT_16](audits/JAVA_AUDIT_16.md)。另结案同源策略拦的是读不是禁脚本、DATETIME 5 字节、SETNX+EXPIRE 非原子、从库可并行应用、FIFO 不是 Redis 淘汰名。见 [JAVA_AUDIT_17](audits/JAVA_AUDIT_17.md)。
