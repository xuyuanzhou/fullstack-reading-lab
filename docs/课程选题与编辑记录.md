# 课程选题与编辑记录

## 选题来源与公开边界

本机题库有前端与 Java 两大方向：前端资料覆盖语言、浏览器、React、项目场景、性能和算法；Java 资料覆盖语言与 JVM、并发、Spring、数据库、Redis、系统设计和算法。我们只用这些目录和主题分布确定课程地图，不把题库文字、图表、图片或密码放入公开站点。

公开课程从“求职者应能解释什么现象”出发独立编写。每节包含问题、核心模型、为何要懂、场景、动手检验、参考答案与依据。当前 706 节中前端 245 节、Java 461 节，合计 2125 个可检索知识点；前端和 Java 都从「全栈主线」读起，先走通一条页面到数据库的功能，再进入各组的机制。其中分布式课先区分三种「一致」，再讲跨服务提交、补偿和对账。前端从全栈主线开始，再按语言、类型、页面、浏览器、网络契约与会话、React 与其数据层、Vue 与其生态、跨端、技术选型（目标端、更新模型，以及各框架对应的路由、状态和数据职责位）、微前端（独立发版边界、组合时机、Federation 与运行时缝、交付契约）、Node 会话、测试、版本边界、Vite 工程排列；Java 从全栈主线开始，再按语言、算法、运行时、并发、数据库与迁移、缓存、JPA 与 Spring、Spring Cloud Alibaba、消息队列（纵览比较与各产品分级）、中间件、搜索、系统设计（含架构演进图）、分布式、过滤链、测试、版本边界、以及一次请求的追踪排列。读者可选择路线并在浏览器里标记进度和待复习。

为加快覆盖，写作分为提取标记和核对发布。先按原件页码把说法写入 [核对队列](核对队列.md)，状态只有已核验、部分已核验、待核验；再批量构造课程草稿。草稿不算已审定知识点，也不进入公开构建。交接方式见 [核对交接](核对交接.md)。Vue 44 页与 MySQL 6 页的说法级队列已全部核完。已发布审查见 audits 目录 FRONTEND/JAVA 第 05–09 批。

## 核验规则

1. **先标版本与范围。** React 以 19.3.0 源码为主；MySQL 示例链接到 8.4 官方手册；Java 示例按课程链接到 Java SE 21 或 25 文档。历史版本表述只有在被误用于当前版本时才判为误导。
2. **先核事实，再做教学简化。** API 行为用官方文档或标准确认；内部实现用固定 tag 源码确认；性能和系统设计结论写明条件与验证方法。
3. **不把规则命中当错误。** 本机文字索引当前有 59 条待复核线索，但绝大多数尚未人工审定。已人工确认的 React 样本见 [知识准确性审查](知识准确性审查.md)。
4. **给出可观察的实验。** 例如状态队列用同一事件中的两种更新方式比较，事务传播画两个事务的提交边界，缓存策略用实际请求和响应头验证。
5. **公开课程不等同于全库验收。** 未完成逐页、逐题核查的私人资料始终标为待核验。

## 图片与版面

本机资料模式即时把 PDF 页面转换成预览图，保留原页的图片、图表和版面；独立图片显示原件。文字层和 OCR 可复制，但 OCR 不是对原页排版的精确复刻。公开网站中机制图从概念重新绘制（含 CAP、Kafka 顺序、布隆、秒杀、消息中间件纵览、架构演进等），不使用购买资料中的图片。对照与修正记录见 [分布式高并发校订记录](分布式高并发校订记录.md)。

## React 内容归属
