# 子任务要不要单独做一页

日期：2026-10-13。结论：**不新增路由。** 子任务继续放在右侧关卡弹窗里，点开后仍进入现有课文地址。

## 对比

| | 新增 `/paths/:gate/sub/:id` 一类路由 | 弹窗里展示子任务 |
| --- | --- | --- |
| 使用时 | 选一关就要离开正在读的课，再跳回来 | 弹窗盖在课文旁边，选完直接打开那一节 |
| 加载 | 再懒加载一页，并走一遍首页/关卡转场 | 弹窗已经在壳层里，展开不再请求页面 |
| 状态 | 关卡已经记在 `/paths?gate=`，课文记在 `/:track/:group/:lessonId`。再加一层，同一件事有三个地址 | 选中关卡仍用现有 `gate` 查询参数和弹窗里的展开状态 |
| 以后加功能 | 子任务正文其实就是课文。新路由会变成第三套关卡页，和关卡地图、课文抢内容 | 地图负责总览，弹窗负责这一关的顺序，课文负责阅读 |

九关的课本来就可以从后面一关打开，不因为「未到」而锁住。弹窗上的「未到」只说明进度还没走到，按钮仍然可点。

## 弹窗里怎么做

- 每一关有状态：已过、进行中、未到、可补。进行中的序号轻轻闪一下，选中时底色变深。
- 阅读和交付合成一条进度。系统要求减少动态效果时，这条进度不再做宽度过渡。
- 展开后的顺序里，每一节标成未读、当前或已读。点进去仍是原来的课文路由。
