# 图标与动画库选型

日期：2026-10-13。对象是本站关卡页，不是整站换图标。

本站是 Vite 8、React 19、TypeScript 的静态页。导航壳已经用 Ant Design 6 和 `@ant-design/icons`。关卡进度存在浏览器本地，页面也要能在没有图标 CDN 的情况下打开。系统开启「减少动态效果」时，关卡不能再播弹簧或闪动。

## 结论

| 用途 | 选用 | 版本 | 落在哪 |
| --- | --- | --- | --- |
| 关卡图标 | `lucide-react` | 1.56.0 | 关卡地图、折叠、锁、星 |
| 关卡动效 | `motion` | 14.1.1，锁死这个版本 | 只在路线页的关卡区块 |

壳层的 `@ant-design/icons` 不动。路线页本来就是懒加载，Motion 只打进这一页的包，不进首页和课文页。

## 怎么量的

2026-10-13 用 esbuild 0.25.10 打包、压缩，并把 `react`、`react-dom`、`react/jsx-runtime` 标成外部依赖。体积是产物字节和 gzip 字节，不是 npm 包解压大小。图标各取 6 个，和关卡页实际会用到的数量同一量级。

## 图标

| 库 | 版本与最近发布 | 6 个图标的 gzip | 和本站的关系 |
| --- | --- | --- | --- |
| lucide-react | 1.56.0，2026-10-13。声明支持 React 16–19 | 2.7 KB。从包入口按名字引入，和直接引单个图标文件一样大 | 选用。SVG 组件，`sideEffects: false`，构建时摇掉没用到的图标，不请求网络 |
| @phosphor-icons/react | 2.1.10，2025-05-22 | 5.1 KB | 不选用。同样 6 个图标大约是 Lucide 的两倍，多字重还会再涨 |
| @iconify/react | 6.0.2，2025-09-15 | 运行时 7.2 KB，图标本体还要再请求 | 不选用。默认向 Iconify API 拉 SVG，静态页离线或页面托管时会空图标 |
| unplugin-icons | 24.0.0，2026-09-11 | 无独立运行时，编译成组件 | 不选用。它是 Vite 插件，适合以后要混很多套图标时再用。现在 6 个图标不值得加一套构建插件 |
| @ant-design/icons | 已在依赖里 | 未单独重测 | 保留。只服务现有导航壳，不把关卡图标绑死在这套外形上 |

Lucide 的包入口会再导出一个图标总表。测量里这个总表被摇掉了，6 个图标仍是 2.7 KB。不要改用 `lucide-react/dynamic` 或 `dynamicIconImports`，那会把整库拉进来。

## 动画

| 库 | 版本与最近发布 | gzip | 和本站的关系 |
| --- | --- | --- | --- |
| motion，`LazyMotion` + `domAnimation` + `m` | 14.1.1。声明支持 React 18–19 | 27.7 KB | 选用。声明式，能读 `prefers-reduced-motion`，只带变换和透明度 |
| motion，直接用 `motion` 组件 | 同上 | 41.8 KB | 不选用这条入口。布局、拖拽等功能关卡用不上 |
| GSAP | 3.15.0，2026-04-13 | 核心 27.8 KB，不含插件 | 不选用。和 Motion 一样重，但是命令式，和现有 React 状态、CSS 动效各写一套 |
| lottie-web | 5.13.0，2025-05-21 | 播放器 79.4 KB，还不包含动画 JSON | 不选用。适合成片插画。本站没有这类素材，关卡状态也不该靠 JSON 播放 |
| @motionone/react | 10.16.4，2023-09-21 | 未安装 | 不选用。Motion One 已经并进 `motion`，这个包三年没有发布 |
| framer-motion | 14.1.1，由 `motion` 带入 | 已含在上面的 Motion 体积里 | 不单独安装。业务代码从 `motion/react` 引入 |

`motion@14.2.0` 在 2026-10-13 发布，但它依赖尚未发布的 `framer-motion@14.2.0`，`npm install motion` 会失败。所以 `web/package.json` 把 `motion` 写成 `14.1.1`，不加 `^`。

## 接入成本

| 方案 | 要改什么 | 以后的负担 |
| --- | --- | --- |
| Lucide 按名字引入 | 一个依赖，组件里直接写 `<Star />` | 低。继续按名字加图标即可 |
| Iconify 运行时 | 一个依赖，还要处理加载失败和离线 | 高。每个图标多一次请求 |
| unplugin-icons | Vite 插件、类型声明、虚拟模块写法 | 中。图标一多才划算 |
| Motion 轻量入口 | 一个依赖，路由页包一层 `LazyMotion` | 低。只允许 `m` 组件，`strict` 会挡住误用完整 `motion` |
| GSAP | 命令式时间轴，要自己接 React 生命周期和减少动效 | 中。和现有 CSS 动效并存 |
| Lottie | 播放器加 JSON 资源 | 高。还要设计素材 |

## 用法

图标从 Lucide 按名字引入。星标点亮时用当前文字色填充，读屏只听到「几星」，单个星不进无障碍树。

```tsx
import { Star } from 'lucide-react'

export function QuestStars({ count }: { count: number }) {
  return (
    <span className="quest-stars" aria-label={`${count} 星`}>
      {[1, 2, 3].map((item) => (
        <Star
          key={item}
          size={14}
          strokeWidth={1.75}
          aria-hidden="true"
          className={item <= count ? 'is-on' : undefined}
          fill={item <= count ? 'currentColor' : 'none'}
        />
      ))}
    </span>
  )
}
```

动效只用变换和透明度。进度条用 `scaleX`，从左边长出，不改布局宽度。系统要求减少动效时不挂 Motion，进度条改成静态宽度。

```tsx
import { LazyMotion, domAnimation, m, useReducedMotion } from 'motion/react'

export function QuestMotionRoot({ children }: { children: React.ReactNode }) {
  const reduce = useReducedMotion()
  if (reduce) return children
  return <LazyMotion features={domAnimation} strict>{children}</LazyMotion>
}
```

对应实现在 `web/src/components/learning/questMotion.tsx`。`QuestBoard` 用它画地图图标、折叠箭头、未解锁的锁、星，以及新解锁时的短弹簧。原有 CSS 仍负责印章和路线图；减少动效的样式表规则也还在。

## 不同设备和浏览器

- 图标是内联 SVG，不依赖图标字体，也不依赖外网。窄屏和桌面用同一套，颜色跟当前主题的文字色。
- 解锁位移和进度缩放走变换，由合成器处理。进度条轨道只有 8px 高。
- `useReducedMotion()` 读的是 `prefers-reduced-motion`。为真时关卡卡片不再做弹簧，折叠箭头也不旋转。
- 路线页在 `web/src/App.tsx` 里懒加载。课文页、首页不下载这份 Motion。

## 明确不做什么

- 不把导航、菜单、主题按钮从 Ant Design 图标换掉。
- 不引入 GSAP、Lottie、Phosphor、Iconify 运行时、unplugin-icons。
- 不把 `motion` 放开到 `^14.2.0`，除非 `framer-motion@14.2.0` 已经在仓库里能安装。
