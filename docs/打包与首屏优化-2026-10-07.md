# 打包与首屏优化

日期：2026-10-07  
范围：`web/` 公开站（Vite 8 + React 19 + Ant Design 6）

## 现状结论

### 优化前基线

| 产物 | 约大小 | 说明 |
| --- | --- | --- |
| `index-*.js` | ~2.3 MB（gzip ~790 KB） | 主壳：antd + React Router + **整份 curriculum** |
| `AiPage-*.js` | ~320 KB | AI 课页（已懒加载） |
| `aiCatalog-*.js` | ~150 KB | AI 目录/样板合并（进 AI 才加载） |
| `aiInterviewBank-*.js` | ~55 KB | 60 题题库（进题库/知识库 AI 搜索才加载） |
| `jsx-runtime-*.js` | ~300 KB | React 相关共享 |

首屏真正的大头不是 AI，而是 **694 课全文被同步打进主包**。`curriculum.json` 源文件约 2.2 MB（带缩进）；minify 后正文仍约 1 MB，几乎整段进入 `index`。

### 本次拆分后（2026-10-07 实测）

| 产物 | 约大小 | 说明 |
| --- | --- | --- |
| `index-*.js` | **~1.07 MB**（gzip ~390 KB） | 主壳 + **curriculum-index**（列表/搜索字段） |
| `curriculum-bodies-*.js` | ~1.22 MB（gzip ~432 KB） | 课内正文；**打开课页才下载**，不进首屏 preload |
| AI / 题库 chunks | 同前 | 仍仅在 AI 相关路由加载 |

主包相对优化前约 **−54%**（2.31 MB → 1.07 MB）。冷开前端/Java 课表不再拉 bodies / AI 数据包。

## 已做（有效）

1. **AI 路由懒加载**：`AiPage` / `AiNotePage` / `AiLabPage` 用 `React.lazy`；侧栏 `AiProgressAside` 仅在 AI 路线加载。
2. **切断 catalog → 题库硬依赖**：`searchAiNotes` 不再 import 题库；知识库分路搜课/搜题。
3. **AppLayout 动态拉 AI catalog**：非 `/ai` 路径不预拉 AI 数据包。
4. **勿用粗暴 `manualChunks`/`codeSplitting.groups`**：曾把 antd 误塞进 `ai-pages` 并被 HTML `modulepreload`，首屏反而更慢。共享依赖留给 Vite 自然拆分。

## 本次继续（课程包）

把课表拆成两层：

| 文件 | 内容 | 加载时机 |
| --- | --- | --- |
| `curriculum-index.json` | 导航/列表/搜索用字段（id、title、prompt、core、points…）+ outline/groupOrder | **同步**进主壳（约 420 KB minify） |
| `curriculum-bodies.json` | 课内正文（why/example/task/answer/deep/references/diagram…） | **打开课页时**动态 `import()` |

导出入口仍是 `scripts/export-curriculum.mjs`（`npm run build` / `predev` 会跑）。完整 `curriculum.json` 保留给校验脚本与交接，运行时主路径不再同步 import 全文。

## 测量方法

```bash
cd web && npm run build
# 看 dist/assets 体积与 index.html 的 modulepreload（不应预载 AI / bodies）
ls -lah dist/assets | sort -k5 -h
```

关注：

- 主包 `index-*.js` 是否下降（目标：从 ~2.3 MB 降到约 1.6–1.8 MB 量级，视 antd 而定）
- 是否出现独立的 `curriculum-bodies-*.js`（仅课页链路）
- 进入前端/Java 课表是否仍流畅；点进一课是否短暂出现「正在打开课程…」后出正文

## 不要做的

- 不要把 antd / React 用自定义 group 绑到 AI chunk。
- 不要为了消 warning 无脑抬高 `chunkSizeWarningLimit` 却不测 preload。
- 不要把 `curriculum-bodies` 再同步 import 回 `AppLayout` / `routes`。

## 下一刀（未做，按收益排序）

1. **antd 按需/换轻量壳**：主包剩余大头是 UI 库；可评估 icon 子集、或侧栏改原生元素。
2. **index 再削 `core`**：知识库搜索可改为独立 `search-index` chunk，主壳可再降 ~190 KB。
3. **按 track 拆 bodies**：`bodies-frontend.json` / `bodies-java.json`，首开某轨只拉一半。
4. **字体**：Google Fonts 外链可改 `font-display: optional` 或自托管子集，减首屏竞争。
5. **HTTP 缓存**：`curriculum-bodies` 与 AI chunk 适合长期 hash 缓存；部署侧确认 `Cache-Control`。

## 验收口令

- `cd web && npm test && npm run build`
- 冷打开站点（非 AI）→ 网络面板不应先下载 `aiCatalog` / `aiInterviewBank` / `curriculum-bodies`
- 打开任意前端/Java 课 → 出现 bodies chunk，正文完整（含 deep / references / diagram）
