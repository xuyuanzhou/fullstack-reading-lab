# 进架构师主线的转场

日期：2026-10-14。只改首页进入 `/paths` 这一下。进课文、返回的动画没有动。

## 原先为什么冲

首页点「按主线学」会铺满一层 1200 毫秒的穿梭。问题不在时长数字本身，而在这一层怎么动：

- 着色器用 `fract` 把径向条纹折返，再用 `atan` 转出大约 10 条旋转光带。折返的瞬间条纹会跳，看起来像频闪。
- 上面还盖着 4 像素一条的扫描线，以及大约 28% 处闪一下的金色内描边。
- 备用画面从 1.18 倍缩放用 `ease-in` 收到 1 倍。缓动是越来越快，缩放又偏大，收尾像被推进去。
- 遮罩底色不透明，时间一到整层直接卸掉，架构师主线是切出来的，不是揭开的。

## 现在怎么动

时长 1500 毫秒，仍低于 2 秒。缓动是 `cubic-bezier(0.22, 1, 0.36, 1)`：先动起来，再慢慢停。

遮罩透明度：0 → 1（前 22%）→ 保持到 45% → 再回到 0。页面从雾下面出来。位移只有向下 12 像素，缩放从 1.03 收到 1。扫描线和金边在这一下不显示。着色器只留一块慢慢变亮的雾，没有折返条纹。

系统要求减少动态效果时，这一层不出现，地址仍然会到 `/paths`。

## 实现

时长在 `web/src/transition/scenes.ts`：`warp` 为 1500。

着色器在 `web/src/transition/warp.ts`：

```glsl
precision mediump float;
uniform float uTime;
uniform vec2 uRes;
void main() {
  vec2 uv = (gl_FragCoord.xy - 0.5 * uRes) / uRes.y;
  float r = length(uv);
  float t = clamp(uTime / 1.5, 0.0, 1.0);
  vec3 base = mix(vec3(0.07, 0.09, 0.08), vec3(0.15, 0.24, 0.20), smoothstep(0.9, 0.08, r));
  float glow = smoothstep(0.7, 0.0, r) * (0.10 + 0.16 * t);
  vec3 col = base + vec3(0.20, 0.34, 0.28) * glow;
  gl_FragColor = vec4(col, 1.0);
}
```

样式在 `web/src/styles/_transition.scss`：

```css
.route-fx.is-warp {
  background: transparent;
  opacity: 0;
  animation: fx-warp-veil var(--fx-ms) cubic-bezier(0.22, 1, 0.36, 1) forwards;
}
.route-fx.is-warp .route-fx-gl,
.route-fx.is-warp .route-fx-fallback {
  animation: fx-warp-drift var(--fx-ms) cubic-bezier(0.22, 1, 0.36, 1) forwards;
}
.route-fx.is-warp .route-fx-scan,
.route-fx.is-warp .route-fx-neon { display: none; }

@keyframes fx-warp-veil {
  0% { opacity: 0; }
  22% { opacity: 1; }
  45% { opacity: 1; }
  100% { opacity: 0; }
}
@keyframes fx-warp-drift {
  from { transform: translateY(12px) scale(1.03); }
  to { transform: translateY(0) scale(1); }
}
```
