# 技能列收起组和展开印章用同一套六边形

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已完成 |

| 作者工具 | Cursor |

## 背景

横滑星图已经把地图放在称号上面，但列里面仍是两套样子：收起的组是左右两列的字，展开后是印章再加一整句进度，窄列里会从字中间断开。列标题还粘在一条浅色底上。

## 决策

- 采用：收起的组改成一枚小六边形，比例写在印心里，组名在下面。展开后只留印章、名称和短状态（未走到 / 可以开始 / 正在点亮 / 读完 / 练过）。长句和「在第 N 关练到」仍在按钮里，悬停或键盘聚焦才显示。列标题不再粘住，也不再铺底。列与列之间不再画通栏竖线。
- 不采用 / 刻意不做：不恢复五列等宽表格。不改折叠、搜索、点亮规则，不把 `aiDone` 写进关卡 `done`。不把已点亮、练过或称号写成认证。不改选择题石径。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/SkillsPage.tsx` | 组按钮里加一枚与技能印章相同顶点的小六边形 |
| `web/src/styles/_reading.scss` | 组、印章、列标题和进度句的排法 |

## 验证

- 桌面 `#/skills`：计算机基础展开后是 TCP / HTTP / HTTPS 印章加一行短状态；前端仍是收起的六边形，比例在印心。长句计算样式为 `opacity: 0`、`max-height: 0`。
- 390×844：视口宽 390，星图宽 358，一列约 280，可横滑。测完已 `Emulation.clearDeviceMetricsOverride`。
