## 背景

技能页原先按课表列了六项。招聘里反复出现的是 Java、Spring、MySQL、Redis、Vue、Docker 这些名字。点亮也要能看出来：前置没完成就发暗，同时只有一项在推进，读完挂着的课才亮。

## 决策

- 采用：节点用猎聘、BOSS 直聘上 Java 全栈岗位反复写的技能，并且只挂课库里已有的课文。列是前端、后端、数据与中间件、高并发、部署与排查。
- 采用：点亮从已读课和 `allOf` 推出来，不另存研究选择。前置没点亮时圆点变灰，课仍可打开。已读过一部分的优先标成正在点亮；都没读过则取页面顺序第一项。读完自己的课才是已点亮。没有自己的课的双框架，要 React 和 Vue 都点亮。
- 采用：本地检查通过时圆点中心多一颗标记，文案写明读完才点亮，这不是认证。
- 不采用：不改九关石台和 `gateCleared`。不把已点亮写成岗位认证或技能通过。不为没有课文的招聘词条加空节点。
