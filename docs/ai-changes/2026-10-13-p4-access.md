## 背景

授权要能拒绝匿名、非拥有者、跨租户和已撤销的账号，同时让真正的拥有者仍能读到自己的订单。查询必须把条件放在参数里。

## 决策

- 采用：`labs/order-g4` 使用 MySQL 8.4。两个租户，四个账号。读取条件是账号未撤销、租户相同、并且 `owner_id` 就是这个账号。角色名会从数据库读出，但不授予这一行。商品查询同时绑定租户、拥有者和商品标识。身份来自请求头 `Account-Id`，只用于这组测试。
- 不采用 / 刻意不做：不接 OIDC，不做文件上传，不做跨站请求伪造。不把请求头当成登录协议。不勾选 P4-02。不把结果写进路线页勾选。不提交，不发布。
