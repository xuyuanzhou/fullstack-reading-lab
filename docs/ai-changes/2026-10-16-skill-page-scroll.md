# 技能树页不再被整页拖着滚

| 字段 | 值 |

| 日期 | 2026-10-16 |
| 状态 | 已完成 |
| 关联 | `docs/ai-changes/2026-10-15-stage-mobile.md` |

| 作者工具 | Cursor |

## 背景

点亮技能树在约 750px 宽时被收成两列，整页高到约 7800px。星图底板还在循环改透明度，已点亮印章用投影滤镜循环发光。滚动平均一帧 39ms，最慢一帧 152ms，页面发卡。窄屏上同一块区域又强制横向吸附，往下划会被左右滑抢走。

## 决策

- 采用：960px 及以下，赛道板高度不超过一屏（`min(68dvh, 640px)`）。左右滑换赛道，上下滑只滚当前这一列。横向吸附改为接近才吸，不再强制。
- 采用：技能页去掉 `perspective`。星点不再循环闪，已点亮只留静止投影。正在点亮仍只转虚线圈。
- 不采用 / 刻意不做：不改点亮规则，不改 `gateCleared`。宽于 960px 仍是多列星图。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/styles/_reading.scss` | 赛道改为屏内滚动；停掉整板闪烁和投影循环 |

## 验证

- 748×915 的 `#/skills`：赛道板高 622px，页高 998px。列内可以滚到下面的印章。滚动该列时平均一帧 16ms，最慢 18ms。
- 点印章没有改学习记录。

## 后续

- [ ] 宽屏多列如果再发卡，再量帧时间，不要把投影滤镜加回循环
- [ ] 勿把 960px 以下改回两列撑满整页

## 给下一模型

1. 先读：本文
2. 再读：`_reading.scss` 里 `@media (max-width: 960px)` 的 `.skill-board`
3. 若续作：保持列在板内滚动
4. 禁区：勿改 `skillGlows` 与 `gateCleared`
