## 背景

412×915 的设备模式里，地图仍是横着的 S 形。第 4 关名字被右边裁成「决定拆不:」，第 5、6 关在屏外。窄屏判断只看舞台宽度，设备模式把视口变窄时不一定切到向下的路；字又写在弯路中间，路和小人都压在字上。

## 决策

- 采用：视口不超过 720px，或舞台窄于 640px，用向下的弯路。关名放在石台外侧，路只走中间。手机上路更细，六关收在一屏高度里。
- 不采用 / 刻意不做：不恢复横向滚动看后两关。不改关卡进度、课序和交付文案。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 窄屏同时听视口和舞台宽度；手机站位改到路的外侧 |
| `web/src/styles/_reading.scss` | 手机地图比例 360/540，路宽收细 |

## 验证

- 412 宽：`.path-map.is-portrait`，六关名字都在视口内，页面没有横向溢出。
- 1600 宽、舞台 832：仍是横向地图，比例 980/460。
