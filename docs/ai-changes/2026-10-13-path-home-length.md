## 背景

架构师主线页把标题、整张当次任务、九关地图和四条补强的全部课链从上到下铺开。地图是每次打开都要看的，做题表单和补强课链不是。整张任务卡把九关挤出第一屏。

## 决策

- 采用：首屏保留标题、页内位置和九关地图。当次任务、并行补强收成两段，默认合上。合上时不挂载这两块；展开后才按块加载。补强展开后用四条标签，一次看一条。页内位置用按钮滚动，不用会冲掉 HashRouter 的锚点。
- 不采用 / 刻意不做：不把当次任务改成独立路由。不删补强课链。不改关卡浮框。不改证据写入。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 地图在上；两段默认合上并懒加载 |
| `web/src/components/SideTracks.tsx` | 四条补强改为标签，一次一条 |
| `web/src/styles/_reading.scss` | 分段间距、地图高度、标签 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json && npx oxlint src/pages/PathPage.tsx src/components/SideTracks.tsx
```

- 结果：`tsc --noEmit` 与 `oxlint` 通过。浏览器 `http://127.0.0.1:5185/#/paths`：宽 748 时九关在第一屏，任务表单未挂载，页高约 1054。宽 390 时标题、位置按钮和地图在第一屏，没有横向溢出。展开后出现当次任务，补强四条标签可切到「云与平台」。
- 未执行：系统读屏软件。没有性能压测；懒加载只少挂两块首屏不看的组件。
