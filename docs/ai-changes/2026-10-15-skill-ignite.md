# 总图入口改成「点亮技能树」

## 背景

闯关总图里技能入口只是一句「打开技能图」下划线按钮，看不出「点亮」这件事，也不够抢眼。

## 决策

- 采用：总图 lead 下做全宽入口卡「点亮技能树」。左侧星座预览跟当前点亮态（发暗 / 可点 / 正在点亮 / 已点亮），中间写已点亮计数与正在点亮项，右侧「点燃」。
- 采用：点击仍去 `#/skills`，顺带播营地轻响（若音效开）。不改九关、不写成认证。
- 不采用：紫光霓虹、默认自动播音乐、把技能树嵌回石台总图。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | `skill-ignite` 入口与点亮统计 |
| `web/src/styles/_reading.scss` | 入口卡、星座、动效与减动效 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
```

- 浏览器 `#/paths`：标题下是「点亮技能树」大入口；点「点燃」进 `#/skills`。
