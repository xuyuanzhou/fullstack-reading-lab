## 背景

窄屏上页头很大，列里的组名、印章标题、状态句和关卡链接各是一号字。展开后长句从字中间断开，和收起的六边形不是同一套排法。

## 决策

- 采用：页头 22px。赛道名、组名、技能名都是 13px，同一套无衬线。状态、印心里的比例、关卡链接都是 12px。印章改到名称左边，和关卡石径同一阅读方向。长进度句只在细指针悬停时出现，点一下不会把整句留在列里。
- 不采用 / 刻意不做：不把八十八项收成闯关那一条九站主路。不改点亮、折叠、搜索和关卡通过规则。

- 390 宽：标题仍是 22px，技能名 13px，一列宽约 280。测完已清除设备尺寸模拟。
