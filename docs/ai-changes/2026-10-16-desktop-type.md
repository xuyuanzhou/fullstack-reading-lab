# 宽屏标题和关卡字收小

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已完成 |
| 关联 | `#/drill/:course`、`#/skills`、`#/paths`、课文 |
| 作者类型 | AI |
| 作者工具 | Cursor |

## 背景

宽屏上的页标题比窄屏还大。技能树和主线标题到 40px 左右，选择题关卡名 18px，说明 14px，一长列显得字很大。

## 决策

- 采用：只在 `min-width: 961px` 收字。关卡名 15px，说明 13px，页标题 20px。技能树和主线标题 26px。课文标题 20px，正文段落 15px。
- 不采用 / 刻意不做：不改 960px 以下的字号。不改石径竖线位置，不改通关和积分。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/styles/_drill.scss` | 宽屏选择题标题、关卡名、说明、选项 |
| `web/src/styles/_reading.scss` | 宽屏技能树、主线、课文标题 |

## 验证

- 浏览器 1920 宽：`#/drill/design` 页标题 20px，关卡名 15px，说明 13px。竖线仍是 `top: 56px`、`bottom: -12px`、`left: 33px`。
- `#/skills` 标题 26px。`#/paths` 标题 26px，入口标题 20px。

## 后续

- [x] 宽屏字号已收
- [ ] 不要把 960px 以下的标题再放大去对齐宽屏

## 给下一模型

1. 宽屏字号写在两份样式末尾的 `@media (min-width: 961px)`
2. 窄屏技能树、主线标题仍用各自的 `clamp`，不要删
3. 禁区：勿改石径 `top` / `bottom` / `left`；勿改 80% 通关
