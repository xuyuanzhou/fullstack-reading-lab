# 技能树宽屏页头和星图对齐

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已废弃 |
| 关联 | `#/skills` |
| 作者类型 | AI |
| 作者工具 | Cursor |

## 背景

技能树页头缩在左边，选路和搜索跟星图不是一条宽度。列名被字距拉开，宽屏上九列再折一次，组名被挤断。

## 决策

- 采用：961px 以上，标题在左，选路和搜索在右，称号和主干横贯整页。1400px 以上星图改成五行两排，每排五列。列名和组名的字距收到 0.04em。搜索时星图改回按内容撑开。
- 不采用 / 刻意不做：不合并赛道，不改点亮和折叠规则。960px 以下仍是左右滑的一列。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/SkillsPage.tsx` | 选路和搜索包进 `.skill-controls` |
| `web/src/styles/_reading.scss` | 宽屏网格、五行两排、列名字距 |

## 验证

- 浏览器 1920 宽的 `#/skills`：页宽 1264px，选路在右上，主干八项一行。星图 5 列，组名如「网络协议」不换行。
