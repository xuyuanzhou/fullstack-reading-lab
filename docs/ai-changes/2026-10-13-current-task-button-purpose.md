## 背景

当次任务上的按钮只写了动作。开始、记下失败、重试、导出和暂停看起来像同一类操作，看不出按下之后记什么、会不会运行命令。

## 决策

- 采用：每颗记录按钮下面写一句结果。没有成立的条目标成「选择 / 已选」。导出和检查导入收进「带走或合并记录」。暂停写成一天后、一周后、一个月后回来。记录规则不变：本站不运行命令，结果仍待复核。
- 不采用 / 刻意不做：不增加真正写入的导入确认。不在浏览器里运行 Maven。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/learning/CurrentTask.tsx` | 按钮文案改成动作加结果 |
| `web/src/styles/_reading.scss` | 记录按钮改成左对齐的两行 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json && npx oxlint src/components/learning/CurrentTask.tsx
```

- 结果：`tsc --noEmit` 与 `oxlint` 通过。浏览器 `http://127.0.0.1:5181/#/paths`：30 分钟题里「选择 / 已选」和「记为已开始」「记下没成立」「另记一次」各有一句结果；导出收在「带走或合并记录」；暂停是「一天后回来」等。没有按下会写入记录的按钮。
