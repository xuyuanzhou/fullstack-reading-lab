# 夜间闯关、技能、选择题收成同一套石色

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-17 |
| 状态 | 已完成 |
| 关联 | 夜间模式闯关、技能、选择题样式不协调 |
| 作者类型 | AI |
| 作者工具 | Cursor |

## 背景

夜间舞台把强调色收成浅松绿，底色是深松绿。闯关石台的顶面和底色几乎同色，站号浮在空里。选择题「可以开始」和确认按钮把强调色当底、舞台色当字，夜间就变成浅色药丸。技能印章是深底加描边，三处对不上。

## 决策

- 采用：只改夜间令牌和选择题上会反色的填充。石面比舞台底亮一档，描边能看出来。当前状态用浅字、描边和少量强调色，和技能场景按钮同一套。
- 不采用 / 刻意不做：不改日间石台和日间深色按钮。不加金色。不改九关和通关规则。已点亮仍不是认证。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/styles/_tokens.scss` | 夜间石面、空闲、描边、台座两侧抬亮 |
| `web/src/styles/_drill.scss` | 夜间「可以开始」、当前石台、当前位置和确认按钮改为深底浅字 |

## 验证

- 结果：夜间 `#/paths` 石台有顶面和侧影；`#/skills` 印章描边与石台同一档；`#/drill` 的「可以开始」和答题「确认这题」是深底浅字描边。日间「可以开始」仍是深松绿底、浅字。未提交答案，没有写入通关记录。
