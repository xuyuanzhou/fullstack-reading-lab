## 背景

顺着文末「下一节」读完一整关，已读数仍是 0。主线页会一直停在第一节，因为进度只认「标记已掌握」。

## 决策

- 采用：主线课文末的下一节（以及本关最后一节回主线）在离开前把当前课记为已读。已经记过的不重复切换。页顶那一行下一节仍只是跳转，不记已读。
- 不采用 / 刻意不做：不从右侧「下一步」自动记已读。不改「标记已掌握」按钮的撤销。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/LessonPage.tsx` | 文末主线卡片离开时写入已读 |

## 验证

- `tsc --noEmit -p web/tsconfig.app.json` 通过
- `fs-four-layers` 文末是「记为已读，下一节」。点后进入 `fs-page-feature`，这一关进度变为 1/8，`fs-four-layers` 在已读里
- 验证后把浏览器里的学习记录恢复成点击前的内容
