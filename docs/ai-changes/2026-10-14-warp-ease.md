# 进架构师主线改为淡入淡出

## 背景

首页进入 `/paths` 的穿梭用折返光带、扫描线和金色闪边，结束时遮罩直接消失。缩放从 1.18 用加速缓动收回，看起来冲。

## 决策

- 采用：这一下改为 1500 毫秒的雾面。透明度先升后降，只移动 12 像素，缩放从 1.03 收到 1。缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。着色器不再使用 `fract` 和 `atan`。
- 不采用 / 刻意不做：不改进入课文和返回的动画。减少动态效果时仍然不播。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/transition/scenes.ts` | 穿梭改为 1500 毫秒 |
| `web/src/transition/warp.ts` | 雾面着色器 |
| `web/src/styles/_transition.scss` | 淡入淡出、小位移，这一下隐藏扫描线和金边 |
| `web/src/transition/audio.ts` | 穿梭提示音不再从低频扫到 2200Hz |
| `scripts/page-transition.test.mjs` | 锁住时长，并禁止折返光带 |
| `docs/架构师主线转场-2026-10-14.md` | 原因、实现和浏览器结果 |

## 验证

```bash
cd web && node --experimental-strip-types --test ../scripts/page-transition.test.mjs
```

- 结果：测试通过。浏览器从首页进入架构师主线：1.5 秒、指定缓动、无扫描线、无金边、缩放 1.03。390px 无横向溢出。减少动态效果时没有遮罩，页面仍打开。
