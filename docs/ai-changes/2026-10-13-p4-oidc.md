## 背景

能力差距清单按课名检索时，OIDC 与 PKCE 为 0。已有 `spring-oauth2-resource` 只讲资源服务器校验 Bearer，不讲依赖方登录。

## 决策

- 采用：在 Java 安全组「鉴权」中、`spring-oauth2-resource` 之后新增 `oidc-id-token-pkce`。依据 OpenID Connect Core 1.0、RFC 7636 和 Spring Security OAuth 2.0 Login。例子写出 `oauth2Login` 与 `issuer-uri`、`scope=openid,profile`。客户端密钥不入库，配置里不写密钥项。
- 不采用 / 刻意不做：不把这节放进九关必读。不勾选 P4-05。不改 `spring-oauth2-resource`。不把 Access Token 写成登录证明。不写「Spring 默认打开 PKCE」；PKCE 按 RFC 7636 写公开客户端的两段口令。不写 Next.js、Helm、Terraform、等保。
