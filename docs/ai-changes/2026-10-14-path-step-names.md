## 背景

阅读阶段的步骤条写着「未解锁」。点上去没有内容，又像把课文锁住。

## 决策

- 采用：步骤显示这一项交付的短名。还在读课文时，点一步只出现这一句要交的话，不出现填写表。主按钮仍是去读这一场。
- 不采用 / 刻意不做：不在阅读阶段用「未解锁」标步骤；不因此锁课文。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/learning/QuestBoard.tsx` | 步骤名换成交付短名；未交卷时显示一句预看 |
| `web/src/styles/_reading.scss` | 预看一句的样式 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
```

- 结果：类型检查通过。
- 浏览器 `/paths`：九站还在，主按钮是「开始这一场」，交付卡片 0 张。步骤是三项的短名，没有「未解锁」。点第 2 步后，下面换成那一项的句子。没有点进课文，也没有点记下。
