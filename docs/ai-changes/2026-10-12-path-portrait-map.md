## 背景

窄屏把横着的地图拉成 620px 再左右滑。一条路被屏幕切成几段，竖着滑页面时还会跟横滑抢手势。

## 决策

- 采用：舞台窄于 540px 时，同一条路改成向下弯。名字写在石台外侧。页面只上下滚。点开一关，这一关在视野里。宽屏仍是横着的六座石台。人仍沿当前这条路走到点开的关。
- 不采用 / 刻意不做：不把整张图缩到字看不清。不改 `gateCleared`、课序、交付文案。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 按舞台宽度切换横路或竖路。换方向时人直接站到那一关。 |
| `web/src/styles/_reading.scss` | 竖路的名字在石台左右。窄屏不再强制横向滑动。 |

## 验证

- 舞台宽 380px：地图宽 380px、高 760px，页面不横向溢出。六关名字都在图内。人在第 4 关石台旁。
- 宽于 540px 仍用横着的弯路。

## 后续

- [x] 过关规则未改。
