## 背景

`/paths` 首屏同时堆着标题、五颗跳转、九关地图和任务板。这一轮改成一场遭遇：到营地、出发去课文、回来看见下一场、用一句话收口。

## 决策

- 采用：首屏只留当前关的标题、一句话目标、一个主按钮、阅读和交付两条细进度，以及地图、支线、暂停三个文字入口。地图和任务板用 `<details>` 默认收起。`?gate=` 只换这一场。课读完后目标写成还缺的那一份交付。
- 不采用 / 刻意不做：不新增路由，不改 `LEARNING_SCHEMA_VERSION`，不锁课文，不把支线写进过关条件，不把自评写成已通过。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/data/learningPaths.ts` | 增加 `encounterPhase`、阶段名和按钮文案 |
| `web/src/pages/PathPage.tsx` | 首屏战役卡；地图与任务板收起；主按钮去课文或打开交付 |
| `web/src/styles/_reading.scss` | 战役卡和细进度条；减少动效时进度条不再过渡 |
| `scripts/learning-platform.test.mjs` | 覆盖可开始、进行中、待验收、可补、已过 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
cd web && node --experimental-strip-types --test ../scripts/learning-platform.test.mjs
```

- 结果：类型检查通过。平台测试 18 条通过，含这一场的阶段。
- 浏览器 `http://127.0.0.1:5175/#/paths`：首屏是「把写入做对」和「继续这一场」，地图与任务板关闭，五颗跳转不在。主按钮在视口内。点地图里的「决定拆不拆」后地址变为 `#/paths?gate=g4`，标题换成这一关，九个站点都可点。主按钮进入 `#/java/database/mysql-acid-c-is-consistency`。390 宽无横向溢出，主按钮仍在视口内。`prefers-reduced-motion: reduce` 时进度条无过渡，按钮可点。试过的最近阅读已写回原列表。
