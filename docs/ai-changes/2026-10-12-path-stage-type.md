## 背景

## 决策

- 采用：左侧是目录，当前关一条细线。右侧是章节：大号淡色序号靠着标题。课序和交付不再画点。颜色只用来标「进行中」。下一节放在读法后面，用下划线错开字脚。窄屏仍是竖排目录，标题不拆行。
- 不采用 / 刻意不做：不改 `gateCleared`、课序、交付文案。不恢复转环、印章和整宽色块。
