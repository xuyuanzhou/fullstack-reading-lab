# 正在点亮的印章带上进度，并滚进星图

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已完成 |
| 关联 | 技能树、闯关总图入口 |

| 作者工具 | Cursor |

## 背景

正在点亮的印章，已读篇数写在悬停才出现的说明里。星图打开时只在带 `?skill=` 回来时才把目标滚进板面，当前这一项若在后面的赛道，第一眼看不到。

## 决策

- 采用：正在点亮的角标写成「正在点亮 3/7」这种已读比。总图点燃卡在名字后面带同一对比。
- 采用：打开技能页或换场景时，若这一项的赛道或印章被板面裁掉，把板面滚到能看见它。已经完全在板内则不动。带 `?skill=` 回来仍按原来的方式对准，必要时再滚页面。
- 不采用 / 刻意不做：不改点亮规则，不点印章，不把每一枚暗星的说明都展开。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/SkillsPage.tsx` | 角标带已读比；对准正在点亮 |
| `web/src/pages/PathPage.tsx` | 点燃卡带同一对比 |
| `web/src/styles/_reading.scss` | 正在点亮的角标不换行 |
