## 背景

打开网站和顶栏「学习路线」进的是总图。原先的课表主页还在 `/:track/:groupKey`，顶栏没有单独入口。带走进度先放在技能树，不在这页。

## 决策

- 采用：顶栏在「学习路线」旁边增加「课表」，打开当前轨道、当前章的课表。只有课表页把它标成当前项。「带走进度」从技能树移到课表，放在进度数字下面。
- 不采用 / 刻意不做：不把 `/` 或「学习路线」改回课表。不在技能树再留一份导入导出。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/AppLayout.tsx` | 顶栏「课表」 |
| `web/src/pages/HomePage.tsx` | 课表页挂上带走进度 |
| `web/src/pages/SkillsPage.tsx` | 去掉带走进度 |
| `web/src/styles/_reading.scss` | 面板不再靠顺序挤到页尾 |

## 验证

- 浏览器：总图点「课表」进入 `#/frontend/fullstack`，标题是「课表」，顶栏「课表」为当前项。点开「带走进度」能看到导出和导入。技能树页没有这项。390px 宽时「选择题」在顶栏右侧，可以横滑出来。
