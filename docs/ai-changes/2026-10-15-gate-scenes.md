## 背景

点进一关之后，页面只剩下一场的说明和交付胶囊。已经读过的场次不再出现，没法点回去看。

## 决策

- 采用：`/paths?gate=` 是这一关的场次石台。已记下的场留在路上，点一场才进 `/paths?gate=&scene=`。
- 采用：已记下的场按钮是「再看这一场」，还没读的是「开始这一场」。两条都能打开课文。
- 采用：支线同样先铺场次石台，点进去再开这一场。
- 不采用：阅读阶段不再把交付胶囊铺在场次图上。课文记完后，「交上这一份」仍留在这一关的图下。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 主线和支线的详情改成场次石台，点进单场 |
| `web/src/styles/_reading.scss` | 场次图收成整卡 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
```

- 结果：退出码 0。
- 浏览器 `#/paths?gate=g1`：8 座场次石台。点第一场进入 `scene=fs-four-layers`，按钮是「开始这一场」，可「回这一关」。回到图上仍是 8 座。
- `#/paths?side=fe`：9 座场次石台。390 宽无横向溢出。
