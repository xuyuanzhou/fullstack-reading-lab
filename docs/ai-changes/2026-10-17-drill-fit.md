## 背景

换行收紧之后，常见内容宽度上 Java 仍要四行或五行。槽位沿用了九关的 136，差几像素就少排一列。

## 决策

- 采用：只在选择题的阅读顺序里把最小槽位收到 112。课名之间仍留出空隙。窄屏仍是两列。
- 不采用 / 刻意不做：九关、支线和 Boss 的槽位不动。不把窄屏挤成三列。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | `row` 为真时桌面最小槽位改为 112 |

## 验证

```bash
node --experimental-strip-types --test scripts/drill.test.mjs
```

- 结果：13 项通过。宽约 750 的内容区里 Java 为五列三行，从左到右，课名不相交，换行线不穿过课名。约 590 宽时为四列四行。390 宽仍是两列。九关第二行仍从右边折回。前端五门在约 750 宽时排成一行。

## 后续
