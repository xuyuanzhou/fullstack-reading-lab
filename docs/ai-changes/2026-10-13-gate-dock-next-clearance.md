# 底部浮框不再挡住下一节

## 背景

关卡入口固定在视口底部。课文学到底时，「主线下一节」落在这块浮框下面，点不到。窄屏上浮框几乎铺满宽度，挡住整条切换。

## 决策

- 采用：有浮框的页面把正文底部留白加到 8.75rem，再加安全区。滚到底时下一节整块停在浮框上方。
- 不采用：不把浮框改到顶部，也不取消折叠入口。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/AppLayout.tsx` | 有关卡浮框时给工作区加上 `has-gate-dock` |
| `web/src/styles/_shell.scss` | 正文底部留白，下一节带滚动边距 |

## 验证

- 浏览器：课文滚到最底。412×915 上「主线下一节」底边在浮框上方 49px，点中的是这一节，不是浮框。360×740 同样整块露出。1000 宽时卡片左右两端也都点在这一节上。
