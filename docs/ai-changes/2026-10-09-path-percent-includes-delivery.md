## 背景

课读完、交付还没勾时，右侧大数字已经是 100%。本关最后一节还没记已读，页顶和侧栏也已经把人送去交交付物。侧栏目录课写着「已掌握」，读起来像刷完就能过关。

## 决策

- 采用：主线上的百分比把已读节数和交付勾选加在一起。第 1 关是 8 节加 3 项交付，课都读完但一项都没勾是 73%，不是 100%。最后一节还没记已读时，页顶只写「文末记为已读，再交交付物」，侧栏同样停在这一节；记为已读仍只在文末卡片。目录课的侧栏改成「查阅」，文案是「已读 x / y 课（查阅，不是过关）」。
- 不采用 / 刻意不做：不在课文里再放勾选框。页顶「下一节」仍然只跳转。
