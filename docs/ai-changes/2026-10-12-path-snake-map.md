## 背景

九关放不进一条横路。再加关时，不能把石台缩小，也不能左右滑动把关名裁掉。

## 决策

- 采用：按舞台宽度决定一行几关。奇数行从左到右，偶数行从右到左。行尾用圆角转弯，路留在关名外侧。走过的是实线，没走到的是细虚线，箭头只标在进行中到下一关。窄屏收紧行距，九关落在一屏里；更矮的屏幕只在地图内部滚动，给底部浮层留出空档。
- 不采用 / 刻意不做：不另留一套横向 S。不把九关压进六关的比例。不加地面光。不改关卡进度、课序和交付文案。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 折返布局、转弯路径、滚动只发生在地图里 |
| `web/src/styles/_reading.scss` | 实线与虚线、未到关只留轮廓、地图限高 |

## 验证

- 宽约 748：一行四关，第二行从右回到左，第九关接在左下。关名都在石台下，页面没有横向溢出。
- 412×915：一行两关，九关都在屏内，地图不再自己滚动。关名一行排下，页面没有横向溢出。
- 360×740：仍是一行两关。地图在固定高度里滚，浮层不压住已经露出的关。
