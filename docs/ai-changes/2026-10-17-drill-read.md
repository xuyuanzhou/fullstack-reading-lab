## 背景

每一块拉成一行之后，Java 的 15 门要横滑才能看见后半段。上一门在屏幕里时，下一门经常已经滑出去。

## 决策

- 采用：选择题仍按块从左往右数。一行排满就换到下一行的最左边，序号不倒过来。换行的线从这一行末尾绕到下一行开头，竖线躲开课名，横线落在课名下面。只有一门的块不再写「1 门」。
- 不采用 / 刻意不做：不恢复横滑。九关、支线和 Boss 仍用蛇形。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | `row` 改成阅读顺序换行，`readTurn` 绕到下一行开头 |
| `web/src/styles/_reading.scss` | 选择题石径不再横滑裁切 |

## 验证

```bash
node --experimental-strip-types --test scripts/drill.test.mjs
```

- 结果：13 项通过。`#/paths` 上 Java 为三行，每行从左到右，下一行从左边的下一门开始；课名与换行线不相交。九关第二行仍从右边折回。点 SQL 优化进入 `#/drill/sql`，页上有「回总图」。390px 宽时 Java 两列，同样从左往右换行，线不穿过课名。
