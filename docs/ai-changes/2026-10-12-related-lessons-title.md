| 字段 | 值 |

## 背景

「邻课」是编课用语（邻近/相关的课），不是业界术语；写在课上「细节」标题里会像专业词。

## 决策

- 采用：学员可见标题统一改为「相关课」；契约禁回写「邻课」。
- 不采用：给「邻课」加点击释义（会把它当成术语）。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `curriculum/coverage-path-08.js` 等 | `deep` 标题「和邻课」→「相关课」 |
| `docs/AI契约-变更记录规范.md` | 公开课用词：不说「邻课」 |
| `web/src/data/curriculum*.json` | 导出 |

## 验证

```bash
node scripts/export-curriculum.mjs
rg "和邻课" curriculum web/src/data --glob '*.{js,json}' || true
```

- 结果：导出通过；课上数据已无「和邻课」，「相关课」共 6 处。
