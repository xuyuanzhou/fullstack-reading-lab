# 技能赛道收成一条石径，只让正在点亮的站发光

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已完成 |
| 关联 | 技能树星图观感 |

| 作者工具 | Cursor |

## 背景

收起的组和展开的印章都是同样亮的六边形，眼睛找不到「正在点亮」。列头又是标题加一条进度，和石径不是一套东西。

## 决策

- 采用：每条赛道一条 2px 石径，印章和收起组都是 44px，压在线的中心。默认组是线色空心。组里已有点亮则描边加重。组里有「正在点亮」才发光；展开后光留在那一枚印章上，印心有一颗实心宝石。还没走到的短状态收起。细指针上，这类站的关卡链接也只在悬停或焦点时出现。触屏仍显示关卡链接。单组的「架构」在印章之间补同一条线。
- 不采用 / 刻意不做：不把八十八项收成闯关九站。不改点亮、折叠、搜索、80% 通过和 `gateCleared`。不把字号放大。不恢复五列网格、金色和系统滚动条。右缘遮罩去掉，名字不再被吃掉。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/SkillsPage.tsx` | 列头包进 `skill-lane-head`；组按钮在含 `research` 时加 `data-live` |
| `web/src/styles/_reading.scss` | 石径、暗站、当前站的光，以及列头一行 |

## 验证

- 桌面 `#/skills`：默认组描边是 `--lab-stage-line`。含「幂等」的组石径为亮色渐变，印章 `drop-shadow`，印心填充为亮色。未走到的短状态 `opacity: 0`。列宽 208px。右缘遮罩为 `none`。
- 390 宽、触控：标题 22px，技能名 13px，长句仍隐藏。未走到的关卡链接保持可见。列宽约 280。「分布式与高并发」不溢出。测完已清除设备尺寸和触控模拟。
