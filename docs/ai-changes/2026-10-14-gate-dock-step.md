## 背景

右下角关卡弹窗展开后，列表被压到大约四行并拦腰截断，下面又把同一关的标题、周数、阅读、交付和读法再写一遍。浮动层变成了第二份营地。

## 决策

- 采用：九关列表保持完整。选中一关时，底下只放这一步：还有课文就显示「下一节」；课文记完或 `focus=deliver` 才显示交付勾选。
- 采用：窄屏点进一关后仍先收起列表，但面板按内容收高，用「返回关卡」回到九关。
- 不采用：在弹窗里再放读法、顺序、周数和重复的进度条。这些留在 `/paths`。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/GateDock.tsx` | 展开内容改成 `DockStep` |
| `web/src/styles/_reading.scss` | 列表不再被详情压成半截；窄屏详情面板按内容收高 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
```

- 结果：退出码 0。

- 390×844：点进一关后面板高约 251，列表先收起；「返回关卡」回到九关。无横向溢出。
