## 背景

## 决策

- 采用：`labs/order-g0` 用 Spring Boot 3.4.5 把订单放在进程内存里。`GET /orders` 一开始是空数组。三条合成订单按提交顺序返回。负数和超过两位小数返回 400，`type` 为 `invalid-amount`，列表长度不变。`page/orders.ts` 在请求失败后保留草稿。构建沿用 Maven Wrapper 3.9.9 和指向 Maven Central 的设置。
- 不采用 / 刻意不做：不用 MySQL，也不用内存数据库代替 `labs/order-g1g2`。不写 React 或 Vue。不把这组测试写进路线页勾选。不勾选 P4-02、P4-03～P4-06 或 P5～P8。不提交，不发布。
