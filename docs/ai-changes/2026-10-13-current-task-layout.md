## 背景

路线页的当次任务把暂停、15/30/60 分钟、没有成立的行为和开始/记下失败排成同一套按钮。15/30/60 实际是换题，失败选项没有可见标题，每段说明都在重复「本站不运行」。

## 决策

- 采用：换题按钮写出分钟和题名，并说明时长是预计、不是倒计时。失败选项单独标成「没有成立的行为」。暂停收到卡片底部「先离开」。本站不执行命令、结果待复核只在本机命令下说一次。30 分钟和 60 分钟的完成条件改成要写下的观察，不再复述记录状态。
- 不采用 / 刻意不做：不改开始、记下失败、重试、保存、暂停和继续的记录规则。不在浏览器里运行 Maven。不把学员写下的结果标成已通过。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/learning/CurrentTask.tsx` | 分组：换题、题目、本机命令、失败选项、操作、先离开 |
| `web/src/data/learningTasks.ts` | 两道实验题的输入和完成条件去掉重复的待复核声明 |
| `web/src/styles/_reading.scss` | 换题和失败选项与操作按钮分开 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json && npx oxlint src/components/learning/CurrentTask.tsx src/data/learningTasks.ts
```

- 结果：`tsc --noEmit` 与 `oxlint` 通过。浏览器 `http://127.0.0.1:5177/#/paths`：30 分钟题的换题、输入、完成条件、本机命令和「没有成立的行为」分开；15 分钟没有这条命令，并出现自评 0 到 4；60 分钟有三条行为。换题后上一题的状态句会清掉。暂停按钮在「先离开」里，本次没有写入暂停。
- 未执行：系统读屏软件。没有在浏览器里运行 Maven。
