# 手机顶栏的复习数量不再被裁掉

## 背景

窄屏顶栏只剩图标，并且靠右排齐。复习清单的数量角标默认伸出按钮右上角，正好落在导航盒外面，被裁掉，右侧淡出也会盖住它。

## 决策

- 采用：宽度不超过 1180px 时，把角标收到按钮内部。720px 以下的横向淡出只留左缘，提示还能往左滑。
- 不采用 / 刻意不做：不改桌面角标位置。不改复习清单的数据。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/styles/_shell.scss` | 窄屏角标内收；手机导航只在左缘淡出 |

## 验证

- 390px 宽：加入一课后再看顶栏。数量 `1` 的盒子在复习按钮内部（左 234、右 248，按钮右缘 250），也在导航盒内。点在数字上命中的是数字本身。
- 1280px 宽：角标仍用原来的外伸位移。

## 后续

- [ ] 若两位数字盖住图标，再单独缩小字号，不要再把角标伸出按钮

3. 不要为了验证去改 `http://127.0.0.1:5175` 上的学习记录
