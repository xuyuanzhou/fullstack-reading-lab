## 背景

这一站同时放着「开始这一场」和一张交付卡片。人还在读课文，却要先填交付。

## 决策

- 采用：阅读阶段只留总图、这一场按钮和交付步骤条。交付卡片等到这一关课文记完、进入待验收再出现。
- 不采用 / 刻意不做：不在阅读时要求写下交付；步骤上的「未解锁」不锁课文。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/pages/PathPage.tsx` | 待验收或已过才把 `handIn` 传给这一站 |
| `web/src/components/learning/QuestBoard.tsx` | `handIn` 为假时只留步骤，不渲染交付卡片 |

## 验证

```bash
cd web && npx tsc --noEmit -p tsconfig.app.json
```

- 结果：类型检查通过。
- 浏览器 `/paths`：九站还在。按钮是「开始这一场」。步骤 3 个，交付卡片 0 张。说明是「这一场还在读。交付等课文记下再写。」没有点进课文。
