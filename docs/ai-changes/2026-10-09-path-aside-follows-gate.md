## 背景

主线课页顶把同一关的交付条目重复一遍，课文被挤到下面。右侧「下一步」仍按整本目录找第一篇未读，人会从这一关被带走。

## 决策

- 采用：主线课页顶只留关名、第几节、这一节要做的事，以及一行下一节。交付条目留在 `/paths`。右侧在主线课上显示「第 N 关」和本关已读节数，下一步是这一关的下一节；最后一节改为回主线交交付物。文末下一节用和章节「下一课」一样的整行卡片。
- 不采用 / 刻意不做：不在课文上再列交付条目。不改非主线课的章节进度。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/components/ProgressAside.tsx` | 主线课按当前关计进度和下一步 |
| `web/src/pages/LessonPage.tsx` | 页顶收成一行；文末下一节用整行卡片 |
| `web/src/styles/_reading.scss` | `.path-turn` |

## 验证

- `tsc --noEmit -p web/tsconfig.app.json` 通过
- `fs-four-layers` 页顶没有交付条目列表；右侧是「第 1 关」「0 / 8」，下一步是第二节
- 从第二节点文末下一节进入第三节，滚动回到页顶
- `js-equality` 右侧仍是「进度」，底部仍是章节下一课
