# 手机顶栏图标不再被左缘淡出裁掉

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-10-16 |
| 状态 | 已完成 |
| 关联 | 顶栏；选择题多了一枚图标之后 |
| 作者类型 | AI |
| 作者工具 | Cursor |

## 背景

720px 以下的顶栏用左缘淡出提示还能往左滑。选择题图标加上之后，一排装不下，淡出正好盖住「学习路线」，看起来像图标被裁掉。

## 决策

- 采用：去掉这块淡出。图标在 32px 到 40px 之间平分剩余宽度。更窄时可以横滑，不显示滚动条，当前页的图标留在可视范围内。复习数量角标仍收在按钮里面。
- 不采用 / 刻意不做：不删掉选择题入口。不改桌面顶栏的文字按钮。

## 改动清单

| 路径 | 变更 |
| --- | --- |
| `web/src/styles/_shell.scss` | 720px 以下取消左缘淡出，图标按剩余宽度收缩 |
| `web/src/components/AppLayout.tsx` | 窄屏横滑时把当前页图标留在可视范围内 |

## 验证

- 390px：六枚图标都在导航盒内，宽度 33px，没有淡出，页面没有横向溢出。
- 320px：图标保持 32px，当前页「选择题」完整可见，左边两枚可滑出来。
