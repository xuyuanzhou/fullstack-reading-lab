# 页面转场

日期：2026-10-13。范围是首页、关卡列表、子关（课文）这三处来回切换。知识库、核验、本机资料不播这些过场。

## 三种效果

| 切换 | 效果 | 时长 | 怎么画 |
| --- | --- | --- | --- |
| 首页 → `/paths` | 星云穿梭 | 1200 毫秒 | 整屏 WebGL。极坐标星带往前冲，边缘一道暖色扫过，不频闪 |
| 关卡列表或首页 → 课文 | 拼接淡入 | 1000 毫秒 | 左右两块板滑开，接缝有一条光，Canvas 粒子从中线散开 |
| 课文或关卡列表 → 上一级 | 镜头拉远 | 900 毫秒 | CSS 3D：`perspective` + `translateZ` 收回，暗角褪掉 |

低性能设备三种都改成 800 毫秒的 CSS，不再开 WebGL 和粒子。系统开启「减少动态效果」时不播过场，也不出声。

音效默认关闭，符合原先「不自动播放音效」。顶栏「音效关 / 音效开」打开后，转场开始的同一刻用 Web Audio 合成短声：穿梭是一声过滤噪声，拼接是一声短音，拉远是下行正弦。没有音频文件要下载，所以没有加载等待。着色器在页面空闲时预编译，用完释放 WebGL 上下文，避免上下文占满后页面变空白。

## 降级

满足任一条就用简化版：CPU 逻辑核不超过 2、设备内存不超过 2GB、浏览器开启省流、没有 WebGL。一次转场里若有至少三帧间隔超过 34 毫秒（低于约 30fps），下一次起改用简化版。

像素比封顶 1.5，避免高分屏把画布撑得太大。

## 测试

场景判断和时长在 `scripts/page-transition.test.mjs`。三种时长都在 800–1500 毫秒。

浏览器里实际点过（桌面宽度，WebGL 可用）：

| 操作 | 结果 |
| --- | --- |
| 关卡列表 → 首页 | `pullback`，900 毫秒，有镜头层，结束后遮罩消失 |
| 首页「按主线学」→ 关卡列表 | `warp`，1200 毫秒，有画布 |
| 关卡坞进入课文 | `splice`，1000 毫秒，左右两块板和粒子画布都在 |
| 课文回首页 | `pullback`，900 毫秒 |
| 390px 宽再进关卡列表 | 遮罩宽 390，页面没有横向溢出 |
| 开启减少动态效果后从课文回首页 | 地址变了，没有遮罩 |

音效开关的 `aria-pressed` 初始是关闭。没有把音效写进学习记录。
