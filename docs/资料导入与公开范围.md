# 资料导入与公开范围

原件不改写。资料库目录写在 Git 忽略的 `config/library.path`，或通过 `READING_LAB_LIBRARY` / `--library` 传入，仓库不保存某台机器的绝对路径。购买资料和解析全文都只在本机 `private-data/`；Git 忽略此目录，公开站点的构建脚本只发布原创课程和原创图。

## 本机资料清点

本次题库快照共有 1,460 个文件。直接可读文件 1,434 个，包括 PDF、Word、文本、图片、XMind、draw.io、WPS、Excel 和一份 JavaScript 文件。三个压缩包另含 556 个受支持的可读文件；612 份直接 DOCX 和压缩包内 6 份 DOCX 合计含有 1,216 张内嵌图片，均以独立的本机阅读条目保存供查看与 OCR。总计 3,210 个本机阅读条目。五份密码 TXT 只用于访问受保护资料，不进入目录和搜索。十二个 `.DS_Store` 不含学习内容。四个 `.chm` 已用本机 7-Zip 抽出正文并接入阅读器，正文只留在 `private-data/chm-extracted/`；两个 `.chw` 是索引，仍然跳过。

加密 Excel 的密码可从附近的密码说明取得；解密发生在内存中。PDF 的密码同样在运行时读取。密码不会写入代码、公开课程或导入报告。

目前 320 个条目尚无可靠可复制文字：310 张图片需要继续识别或人工复核；其余 10 个中，3 份 TXT 文件大小为零、2 份旧 DOC 的每个内容字节均为 `0x00`、4 份 DOCX 没有正文或内嵌图片，1 份压缩包内 DOCX 只有图片且图片已另列为阅读条目。拍摄模糊的图片即使 OCR 输出很多字，也不会自动视作正确文本。

## “已解析”与“已核验”的区别

本机导入表示文字层、可转换文本或 OCR 结果已可搜索和复制，不代表资料中的每个结论都正确。扫描图、复杂排版和思维导图的 OCR 可能漏字或乱序，应同时查看原图。公开课程会重新组织问题、核对官方资料与版本边界后独立撰写；原题目合集、长段原文和原图片不随站点发布。

配置好资料库后，运行 `python3 reader/import_archives.py`、`python3 reader/import_embedded.py`，再重复运行 `python3 reader/import_library.py --batch-size 200`，可以按稳定的路径顺序逐批更新自己的资料。进度、失败项与索引保存在 Git 忽略的 `private-data/`。公开内容数量以 README 与内容校验结果为准，不等于本机阅读条目数量。

阅读器里的「我的资料」按 MySQL、Vue、并发、面经等科目浏览；这个分类不移动原件。`python3 reader/mark_sources.py` 只把正文中的网站地址写入私有库。
