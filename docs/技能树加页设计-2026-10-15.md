## 现在有什么

- 路线图 §3 写了 38 个能力单元（B/J/R/V/F/D/M/H/T/O/C/S/W/A）。
- `#/skills` 画招聘里反复出现、并且课库或 AI 目录已经有课的技能，共 88 项。在原先的 JavaScript、React、Vue、Java 并发、Spring、MyBatis、MySQL、Redis、消息队列、幂等、限流熔断、Docker、Kubernetes、Nginx、安全、线上排查、双框架，以及 TypeScript、HTTP、Vite、服务端渲染、Pinia、服务端状态、Java 基础、JVM、JPA、Netty、网关、算法、SQL、Elasticsearch、Kafka、表结构、连接池、分布式一致、待发事件、补偿、分布式锁、持续集成、可观测、测试、Compose、CDN、错误预算、密钥、服务拆分、聚合边界、架构决策之外，再补 CSS、HTML、浏览器、TCP、HTTPS、WebSocket、性能优化、微前端、Node.js、React Native、Flutter、小程序、设计模式、AOP、Spring Security、OpenFeign、Nacos、Dubbo、Seata、PostgreSQL、MongoDB、RabbitMQ、RocketMQ、对象存储、Sentinel、压测、Linux、Git。没有课文的单元仍不画。
- `skillSatisfied` 只在测试和双框架标记里用。阅读数不能推出技能通过。

## 页面

- 路由 `#/skills`。总图上加一个入口，不把节点画进九关石台。
- 赛道与子分类、组内顺序以 `docs/技能树结构-2026-10-15.md` 为准：计算机基础 → 前端 → Java → 数据存储 → 中间件 → 分布式与高并发 → 工程与运维 → AI → 架构。直接前置用 `allOf`，一节点最多两个，只表示缺了它就读不懂。网络要 TCP→HTTP→HTTPS/WebSocket；Web 入门 HTML→CSS/JS；Java 语言点亮后才亮 Netty 与 Spring；SQL 点亮后才亮 MySQL。Redis、消息队列、分布式一致不绑 MySQL。Sentinel 在限流熔断后面。前端不再设「其他」。技能页可切全图、浏览器应用、Java 服务、AI 应用，只改正在点亮从哪条路里挑。有两个以上分组的列，组默认收起，正在点亮或从课返回的那一组展开，点组名可开合。只有一个组的列保持展开。按名称找只筛画面。窄屏上星图在称号和主干前面。列不合并。其余前置摘要见结构文档第 6 节。
- 点一个节点，打开它挂着的第一篇未读课。课始终可开。课页和 AI 笔记页有「回技能树 · 这项」，浏览器返回也回到 `#/skills?skill=这项`，窄屏会把那一列滑回来。没有对应课的节点写「课库还没有这一课」，不造空石台。
- 节点可以写「在第 n 关练到」，链到现有 `#/paths?gate=`。这条链接不改变关卡状态。

## 状态从哪来

不新增存储，不写 `pathChecks`、`skipVerify` 或 `gateCleared`。

点亮只看已读课和前置，不另存「正在研究哪一项」。

| 显示 | 条件 | 不表示 |
| --- | --- | --- |
| 发暗 | 前置还没点亮 | 课被锁住。课仍可打开 |
| 可以开始 | 前置已点亮，自己的课还没读完，且不是当前那一项 | 已经在研究 |
| 正在点亮 | 可以开始的里面，优先已读过一部分的；都没读过则取页面顺序第一项。同时只有一项 | 学员选定的研究，或能力已通过 |
| 已点亮 | 自己挂着的课都读过；没有自己的课时，全部前置已点亮 | 岗位认证、技能通过、新版已通过 |
| 本地检查多亮一点 | 挂在这个技能上的基础验证是本地检查通过 | 读完，或认证 |

进阶记下不点亮技能。阅读数不写成技能通过。

## 给下一模型

1. 先读：本文，以及 `docs/ai-changes/2026-10-15-skill-checks.md`。闯关页仍不画树、不锁课文。
2. 再读：`learningSkills.ts` 的 `SKILL_VIEWS` 与 `skillGlows`。
3. 基础验证的 `skillIds` 已接上。进阶题即使写了技能，本地检查也不点亮印章。若续作：只给课库里已有课文的单元加节点。
4. 禁区：勿改 `gateCleared`；勿把「已点亮」写成技能通过或认证；勿把这一页放进关卡石台；勿为了招聘词条去加没有课文的空节点。
